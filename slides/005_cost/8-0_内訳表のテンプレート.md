# 内訳表のテンプレート

**演習で使うスプレッドシート**

---

## シート1: 内訳表

| 列 | 内容 |
|---|---|
| 項目 | サービスや使用タイプ |
| 金額 | 円 |
| 構成比 | 金額 ÷ 合計 |
| 下げ幅の予想 | % |
| 削減額の上限 | 構成比 × 下げ幅 |
| 出どころ | メモ |

---

## 構成比の式

- 構成比 = **項目の金額 ÷ 合計**
- 合計のセルは**固定**しておく(下の行にコピーしてもずれない)

---

## 換算レート

- ドルの単価を使うときは、**換算レートを1つのセル**にまとめる
- 例: 1ドル = 150円
- 他のセルはすべてこのセルを参照
- レートを変えたいときも、1か所を直すだけ

---

## シート2: 比較表

| 列 | 内容 |
|---|---|
| 案 | 削減案の名前 |
| 年額の削減額 | 円 |
| 性能への影響 | 実測と比較 |
| 承認の手間 | 取り直しの要否 |
| 一時コスト | 円 |
| 回収期間 | か月 |

---

## 2つの式

- **回収期間 = 一時コスト ÷ 月の削減額**
- **年額の削減額 = 月の削減額 × 12**

この2つで、案の損得が揃う

---

## 使い方

1. シート1で、**優先順位**を決める
2. シート2で、上位の項目の**削減案を比べる**
