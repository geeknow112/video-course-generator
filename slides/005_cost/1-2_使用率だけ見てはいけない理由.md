# 使用率だけ見てはいけない理由

**低い使用率 ≠ 大きな削減額**

---

## 今回の事例の構成

- Amazon FSx for Windows File Server
- ストレージ: 7.2TB **SSD**
- スループット: 32MB/s
- マルチAZ / 東京リージョン
- 月額 **約31.8万円**(年 約382万円)

---

## 最初に疑ったこと

- スループットを張りすぎていないか
- CloudWatchで7日間を実測
- 使用率は最大でも **0.25%**

---

## でも、金額にすると

- 32→8MB/s に削減しても
- 月 **7,920円** の削減
- 年でも **約9.5万円**
- 75%減らしても、月額全体の中では小さい

---

## 理由と、効いたこと

- スループットの費用そのものが、月額の中で小さい
- 使用率の低さ ≠ 削減額の大きさ
- 実際に効いたのは **ストレージの種類(SSD→HDD)**
