# ターミナル環境の整え方

**IDEなしで快適に**

![bg right:40%](https://images.unsplash.com/photo-1555949963-ff9fe0c870eb?w=800)

---

## Windows Terminalのペイン分割

```
縦分割（左右）: Alt + Shift + +
横分割（上下）: Alt + Shift + -
ペイン間移動:   Alt + 矢印キー
```

左ペイン：Claude Code起動
右ペイン：ファイル確認・コマンド実行

![bg right:35%](https://images.unsplash.com/photo-1518432031352-d6fc5c10da5a?w=800)

---

## エディタはビューワーとして使う

```bash
# 現在のディレクトリをVS Codeで開く
code .
```

VS Codeは**編集はしない**
ファイルツリーの確認とコード閲覧専用

実際の編集はClaude Codeに任せる

![bg right:35%](https://images.unsplash.com/photo-1512758017271-d7b84c2113f1?w=800)

---

## 実際の作業フロー

```
1. Windows Terminalを開く（ペイン分割）
2. プロジェクトディレクトリに移動
   $ cd path/to/project && claude
3. 作業内容を指示
4. Claude Codeが自動でファイルを編集
   右ペインで変更を確認
5. 問題なければコミット
```

![bg right:25%](https://images.unsplash.com/photo-1460925895917-afdab827c52f?w=800)

---

## 「IDEがない」は欠点ではない

- ファイル探索・関数ジャンプも全部頼める
- 意外と不自由しない

**AIに全部任せるという割り切り**
慣れるとIDE時代より速く開発できる
