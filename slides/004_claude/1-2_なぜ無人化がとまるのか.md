# なぜ無人化が止まるのか

**結論：見ているレイヤーが違った**

![bg right:40%](https://images.unsplash.com/photo-1551434678-e076c223a692?w=800)

---

## 「動くはず」が動かなかった

- 読み取り専用コマンドを`permissions.allow`に登録
- 承認作業自体は減っていた

**それをベースに夜間バッチを組んだところ**

`git push` / `gh pr create` の手前で停止
許可リストに追加してもセッション中は反映されない

![bg right:35%](https://images.unsplash.com/photo-1498050108023-c5249f4df085?w=800)

---

## 許可リストの中身を見直すと

意図的に除外していたもの:
- `git push` / `git commit`
- `gh pr create`
- ファイルの新規作成・書き換え全般

**安全性優先の設計 → 書き込み系はスコープ外だった**

![bg right:35%](https://images.unsplash.com/photo-1507925921958-8a62f3d1a50d?w=800)

---

## `claude --help` で見つけたもの

```
--permission-mode <mode>
  (acceptEdits, auto, bypassPermissions,
   manual, dontAsk, plan)

--dangerously-skip-permissions
  チェックを丸ごとスキップ
```

**許可リスト**＝コマンド単位で許可
**バイパス系**＝レイヤーごとスキップ
→ 別物だった

![bg right:30%](https://images.unsplash.com/photo-1461749280684-dccba630e2f6?w=800)

---

## `acceptEdits`にしていたのに止まった理由

`defaultMode: "acceptEdits"`

- ファイル編集（Edit/Write）の確認は自動承認
- **許可リストにないBashコマンドの確認は免除しない**

見ていたレイヤーがそもそも違った

![bg right:35%](https://images.unsplash.com/photo-1454165804606-c3d57bc86b40?w=800)
