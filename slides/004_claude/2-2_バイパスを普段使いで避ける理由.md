# バイパスを普段使いで避ける理由

**`--dangerously-skip-permissions`**

![bg right:40%](https://images.unsplash.com/photo-1551288049-bebda4e38f71?w=800)

---

## 公式ヘルプの一文

```
--dangerously-skip-permissions
  Bypass all permission checks.
  Recommended only for sandboxes
  with no internet access.
```

**インターネット接続のないサンドボックス限定の推奨**

![bg right:35%](https://images.unsplash.com/photo-1555949963-aa79dcee981c?w=800)

---

## 普段使いのマシンで使うと

- 読み込んだWebページやリポジトリに
  悪意ある指示が仕込まれていた場合
- それを**疑いなく実行してしまうリスク**（プロンプトインジェクション）

許可リスト＝人間が事前に許可を決める
フルバイパス＝**エージェントの判断を全面的に信頼**

![bg right:35%](https://images.unsplash.com/photo-1618477388954-7852f32655ec?w=800)

---

## 安全に無人化する考え方

```
母艦（普段使いのマシン）
  bypassPermissionsは使わない
  許可リストで読み取り系だけ自動化
      ↓ 作業を切り出して依頼
使い捨ての隔離環境（EC2など）
  この中だけでbypassPermissionsを使う
  被害が出てもこの環境内に収まる
```

![bg right:30%](https://images.unsplash.com/photo-1614624532983-4ce03382d63d?w=800)
