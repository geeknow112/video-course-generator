# 許可リストとバイパスは別レイヤー

**判定フローで整理する**

![bg right:40%](https://images.unsplash.com/photo-1512758017271-d7b84c2113f1?w=800)

---

## 判定の入口

```
コマンド/ツール呼び出しが発生
  ↓
permission-mode は?
```

`bypassPermissions` / `--dangerously-skip-permissions`
→ **チェックを丸ごとスキップ**（常に確認なし）

![bg right:35%](https://images.unsplash.com/photo-1484480974693-6ca0a78fb36b?w=800)

---

## Bashコマンドの場合

```
acceptEdits / auto / manual / dontAsk / plan
  ↓
Bashコマンドか？
  ↓ Yes
settings.json の allow/deny に一致する?
```

- **deny一致** → 実行拒否（チャットで許可と言っても通らない）
- **allow一致** → 確認なしで実行
- **どちらにも無い** → 毎回ユーザーに確認

![bg right:30%](https://images.unsplash.com/photo-1460925895917-afdab827c52f?w=800)

---

## Edit/Writeの場合

```
Bashコマンドでない（Edit/Write等）
  ↓
acceptEdits か?
```

- **Yes** → 確認なしで実行
- **No** → 毎回確認

![bg right:35%](https://images.unsplash.com/photo-1531297484001-80022131f5a1?w=800)

---

## 過去の許可リストはどこにいたか

`grep` / `cat` / `git log` などは **「allowに一致」の枝だけ**を充実させたもの

`git push` / `gh pr create` は未登録
→ **「毎回確認」の枝に落ちて停止していた**

![bg right:35%](https://images.unsplash.com/photo-1556075798-4825dfaaf498?w=800)
