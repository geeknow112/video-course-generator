# ボーナス
## カスタムテーマを`grep -a`だけで解明する

---

## きっかけ

入力欄の背景色を紫にしたかった

`/config`で選べるのは7種類の組み込みテーマのみ

settings.jsonのスキーマには
`"pattern": "^custom:.*"` が定義されている

→ ドキュメントは一切なし

---

## バイナリを直接読む

```
grep -a -o -E "custom[Tt]hemes?[a-zA-Z0-9_./-]*" claude.exe
```

```
customThemeRef
customThemes
```

芋づる式に関数名を追跡
→ 保存場所は `~/.claude/themes/` と判明

---

## 保存処理から構造を割り出す

```
~/.claude/themes/<slug>.json
{ name, base, overrides }
```

- `base`は組み込みテーマを継承元に指定
- `overrides`は**baseが持つキーだけ有効**（無いキーは無視）
- 発見したキー: `userMessageBackground` 等

---

## 値のバリデーション形式

- `rgb(r, g, b)`
- 16進6桁 / 3桁
- `ansi256(n)`
- `ansi:`プレフィックス

```json:~/.claude/themes/purple-input.json
{ "name": "purple-input", "base": "dark",
  "overrides": {
    "userMessageBackground": "rgb(88, 28, 135)" } }
```

---

## まとめ

- 使ったコマンドは実質**十数回のgrep**、所要**10分程度**
- キーポイント：**保存関数／ロード時フィルタ／値検証関数**を芋づる式に追う
- 巨大オブジェクトを一気に読まず、処理の入口関数から辿る
