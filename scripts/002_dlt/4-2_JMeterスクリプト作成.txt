ここからハンズオンです。
JMeterをインストールして、じっさいにスクリプトをつくります。
つくるのは、APIにGETリクエストをなげるだけのかんたんなものです。
まずはうごくものをつくって、そこからふやしていきます。
---
まずインストールです。
Apache JMeterのこうしきサイトをひらきます。
Download Releasesから、さいしんばんをダウンロードします。
Zipをてんかいして、binフォルダのなかのjmeterをじっこうすれば、GUIがたちあがります。
Windowsならjmeter.bat、MacやLinuxならjmeterというファイルです。
Javaがひつようなので、はいっていないばあいはさきにいれてください。
きどうにすこしじかんがかかります。まっててください。
---
Thread Groupをつくります。
Test Planをみぎクリックして、Add、Threads、Thread Groupのじゅんにえらびます。
ここでせっていするのは3つです。
Number of Threadsは、かそうユーザーのにんずう。
Ramp-up periodは、そのにんずうにたっするまでのびょうすう。
Loop Countは、なんかいくりかえすかです。
ローカルでかくにんするだけなら、1にん、1びょう、1かいでじゅうぶんです。
ほんばんのふかは、DLTがわのせっていできめるので、ここはちいさくしておいてかまいません。
---
HTTP Requestをついかします。
Thread Groupをみぎクリックして、Add、Sampler、HTTP Requestをえらびます。
Protocolには、httpsまたはhttpをいれます。
Server Name or IPに、たいしょうのホストめいをいれます。ここにはURLぜんたいではなく、ホストめいだけをいれます。
Pathに、たたきたいパスをいれます。スラッシュからはじめます。
Methodは、GETやPOSTからえらびます。
ここでよくあるまちがいが、Server Name or IPにhttpsからはじまるURLをまるごといれてしまうことです。
そうするとせつぞくできません。ホストめいだけにしてください。
---
HTTP Header Managerをついかします。
Thread Groupをみぎクリックして、Add、Config Element、HTTP Header Managerです。
ここにContent-Typeや、にんしょうようのヘッダーをついかします。
APIをテストするばあい、これがないとリクエストがはじかれることがあります。
User-Agentをせっていしておくのもおすすめです。
サーバーがわのログで、ふかテストからのリクエストだとみわけがつくようになります。
---
スクリプトをほぞんします。
File、Save Test Plan asをえらび、api-load-test.jmxのようななまえをつけます。
このjmxファイルが、DLTにアップロードするファイルになります。
なかみはXMLなので、テキストエディタでもひらけます。
Gitでかんりしておくと、へんこうのりれきがのこるのでおすすめです。
---
できあがったこうせいをかくにんします。
Test Planのしたに、Thread Groupがひとつ。
そのしたに、HTTP RequestとHTTP Header Managerがならんでいるはずです。
ローカルで1かいだけじっこうして、エラーがでないことをたしかめておくと、あとがらくです。
かくにんには、View Results Treeというリスナーをいちじてきについかします。
レスポンスのなかみがみえるので、ただしくつながっているかがわかります。
たしかめたら、リスナーはけしてください。DLTでじっこうするときにはふようです。
---
つぎのレクチャーでは、このスクリプトをDLTにアップロードして、じっさいにおおきなふかをかけます。
ローカルで1にんでうごいたものが、クラウドで100にんぶんうごきます。
