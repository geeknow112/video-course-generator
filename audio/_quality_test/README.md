# 音声品質比較（feature/voice-quality）

`scripts/003_kiro/1-1_コース紹介.txt` の冒頭1ページを、
VOICEVOX（四国めたん ノーマル / speaker=2）で
パラメータを変えて合成した比較用サンプルです。

既存コース（`audio/003_kiro/`、`audio/001_cicd/`）は一切上書きしていません。

## 聴き方

1. まず `baseline_*.wav` を聴く（現在の本番設定＝無加工）。
2. 次に `A` を聴く。**これが今回の推奨案**です。
3. 気になれば `B`〜`G` を聴き比べる。
4. 良いと思ったファイル名（パラメータ）を教えてください。それを本番の既定値にします。

## 読み間違い（辞書未登録の状態で実際に確認したもの）

`misread_check_unregistered.wav` で以下がどう読まれるか確認できます。

- `npm` → 「ンプ」と読まれる（正しくは「エヌピーエム」）
- `Q2` → 「キュウツウ」と読まれる（正しくは「キューニ」。Q1・Q3は正しく読める）
- `VS Code` → 「バーサスコード」と読まれる（「VS」を"versus"と解釈している。正しくは「ブイエスコード」）
- `Hooks` → 文脈によって「エイチウックス」と読まれることがある（「フックス」が正しい読み）。
  「Hooksを使います」のように直前に読点がないと発生し、
  「Steeringと、Hooksを使います」のように読点を挟むと正しく読める。不安定なので辞書登録で固定するのが安全。

詳細と登録候補一覧は本文の報告を参照してください。
